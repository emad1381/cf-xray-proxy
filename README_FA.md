# ⚡ CF Xray Proxy (پیشرفته)

**پروکسی قدرتمند و سریع روی کلودفلر ورکر برای پروتکل‌های VLESS / VMESS / Trojan**

[Click here for English Documentation](README.md)

این پروژه یک اسکریپت بهینه‌سازی شده برای Cloudflare Worker است که ترافیک پروتکل‌های Xray (شامل VLESS، VMESS و Trojan) را از طریق WebSocket یا HTTPUpgrade به سرورهای اصلی شما منتقل می‌کند. این اسکریپت به عنوان یک Load Balancer هوشمند عمل می‌کند و در صورت از کار افتادن یک سرور، ترافیک را به سرورهای سالم هدایت می‌کند.

## 🚀 ویژگی‌های کلیدی

*   **لود بالانسینگ هوشمند (Smart Load Balancing):** پشتیبانی از روش‌های توزیع بار وزنی (Weighted) و جلسات پایدار (Sticky Sessions).
*   **دسترس‌پذیری بالا (High Availability):** تشخیص خودکار سرورهای خراب و انتقال ترافیک به سرورهای سالم (Failover).
*   **بررسی سلامت لحظه‌ای (Real-Time Health Checks):** پینگ کردن مداوم سرورها برای سنجش سرعت و وضعیت اتصال.
*   **پشتیبانی کامل از پروتکل‌ها:** سازگار با **VLESS**، **VMESS** و **Trojan** بر بستر WebSocket و HTTPUpgrade.
*   **امنیت و مخفی‌سازی:** قابلیت تغییر آدرس چک کننده وضعیت (Health Path) و مخفی کردن آدرس سرورهای اصلی.
*   **محدودیت سرعت (Rate Limiting):** امکان محدود کردن تعداد اتصالات همزمان برای هر کاربر (IP).
*   **نصب آسان:** تنها یک فایل `worker.js` که به راحتی در کلودفلر کپی می‌شود.

## 🛠️ تنظیمات (Environment Variables)

برای شخصی‌سازی ورکر، متغیرهای زیر را در بخش **Settings -> Variables** در داشبورد کلودفلر اضافه کنید.

<div dir="rtl">

| نام متغیر | ضروری؟ | پیش‌فرض | توضیحات |
| :--- | :---: | :---: | :--- |
| **`BACKEND_LIST`** | ✅ | - | **مهم‌ترین تنظیم.** لیست آدرس سرورهای بک‌اند شما. <br>فرمت: `url` یا `url|weight`. <br>مثال: `https://s1.example.com, https://s2.example.com|5` |
| **`BACKEND_URL`** | ❌ | - | *فال‌بک.* آدرس تک سرور (اگر `BACKEND_LIST` را وارد نکنید). <br>مثال: `https://my-vless-server.com` |
| **`HEALTH_PATH`** | ❌ | `/health` | **امنیت.** مسیری که برای چک کردن وضعیت سرورها استفاده می‌شود. <br>مثال: `/secret-status` (با این کار آدرس پیش‌فرض `/health` غیرفعال می‌شود). |
| **`HIDE_BACKEND_URLS`** | ❌ | `true` | **حریم خصوصی.** اگر `true` باشد، آدرس سرورها در خروجی Health Check مخفی می‌شود. برای دیدن Ping و آدرس‌ها، روی `false` بگذارید. |
| **`BACKEND_HEALTH_CHECK_INTERVAL`** | ❌ | `30000` | فاصله زمانی بین چک کردن خودکار سرورها (به میلی‌ثانیه). پیش‌فرض ۳۰ ثانیه است. |
| **`MAX_RETRIES`** | ❌ | `3` | تعداد دفعات تلاش مجدد برای اتصال به سرور در صورت خطا. |
| **`BACKEND_STICKY_SESSION`** | ❌ | `false` | اگر `true` باشد، سعی می‌کند کاربر را همیشه به همان سرور قبلی وصل کند (مفید برای برخی سایت‌های بانکی). |
| **`DEBUG`** | ❌ | `false` | فعال‌سازی لاگ‌های دقیق برای عیب‌یابی در داشبورد کلودفلر. |
| **`RATE_LIMIT_ENABLED`** | ❌ | `false` | فعال‌سازی محدودیت تعداد اتصال برای هر IP. |
| **`RATE_LIMIT_MAX_CONN_PER_IP`** | ❌ | `5` | حداکثر تعداد اتصال همزمان مجاز برای هر IP کاربر. |

</div>

## 📡 نحوه استفاده (API Endpoint)

### بررسی سلامت سرورها (Health Check)
آدرس: **`https://YOUR_WORKER.workers.dev/<HEALTH_PATH>`** (پیش‌فرض: `/health`)

این صفحه وضعیت لحظه‌ای تمام سرورهای شما را نشان می‌دهد.

**نمونه خروجی (وقتی `HIDE_BACKEND_URLS=false` باشد):**
```json
{
  "status": "ok",
  "timestamp": 1723456789000,
  "totalBackends": 2,
  "healthyBackends": 2,
  "backends": [
    {
      "url": "https://server1.example.com",
      "healthy": true,
      "latency": 45,        // پینگ سرور (میلی‌ثانیه)
      "failureCount": 0
    }
  ]
}
```

### صفحه اصلی
به صورت پیش‌فرض، اگر کسی آدرس اصلی ورکر (`/`) را باز کند، به سایت `aparat.com` ریدایرکت می‌شود تا ماهیت پروکسی مخفی بماند.

## 📦 آموزش نصب و راه‌اندازی

### روش ۱: کپی پیست دستی (سریع‌ترین)
1.  فایل `worker.js` را از این مخزن دانلود کنید (یا محتویات آن را کپی کنید).
2.  به پنل **Cloudflare Dashboard** بروید و یک Worker جدید بسازید.
3.  روی دکمه **Quick Edit** کلیک کنید.
4.  تمام کدهای موجود را پاک کرده و کد `worker.js` را جایگزین کنید.
5.  دکمه **Save and Deploy** را بزنید.
6.  به تب **Settings -> Variables** بروید و متغیر `BACKEND_LIST` را با آدرس سرورهای خود مقداردهی کنید.

### روش ۲: استفاده از Wrangler (برای توسعه‌دهندگان)
1.  نصب وابستگی‌ها: `npm install`
2.  بیلد کردن پروژه: `npm run build` (فایل `worker.js` ساخته می‌شود)
3.  دیپلوی در کلودفلر: `npx wrangler deploy`
